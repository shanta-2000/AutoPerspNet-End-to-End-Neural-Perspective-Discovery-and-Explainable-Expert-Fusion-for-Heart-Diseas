Heart disease prediction is an important healthcare application of machine learning. 
Traditional neural networks process all patient features through one shared model. 
Although these models can achieve good prediction performance, their internal decision structure is difficult to interpret. 
Multi-Perspective Machine Learning, or MPML, improves interpretability by dividing features into several meaningful perspectives.


However, MPML depends on manually or statistically constructed feature groups.
